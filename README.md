# Portfolio Responsive Complete

A responsive personal portfolio website built with **HTML, CSS, and JavaScript**, featuring an integrated **AI Chat Assistant**.

## 🚀 Live Demo

[View Portfolio](https://547jaswanth.github.io/portfolio-responsive-complete-main/)

![Portfolio Preview](/preview_.png)

## ✨ Features

- Fully responsive personal portfolio website using HTML, CSS, and JavaScript.
- Built with a Mobile First approach and optimized for desktop.
- Smooth scrolling across all sections.
- Scroll-based animations for an engaging user experience.
- Sections include Home, About, Experience, Education, Training, Skills, Work, and Contact.
- Integrated **AI Chat Assistant** to help visitors learn more about my experience, skills, projects, and background.
- Compatible with all modern mobile devices.
- Clean, modern, and professional user interface.

## 🤖 AI Chat Assistant

The portfolio includes an AI-powered chat assistant that allows visitors to ask questions about:

- Professional experience
- Technical skills
- Projects and work
- Education and certifications
- Contact information

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- AI Chat Assistant integration
